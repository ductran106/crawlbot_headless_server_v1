Đây anh, **lệnh “stop chuẩn”** cho lane này:

```bash
pkill -f 'python.*zalo|python.*crawler|chromedriver|chrome.*chrome_user_data'
```

Nếu muốn kiểm tra trước/sau khi stop:

```bash
pgrep -af 'python.*zalo|python.*crawler|chromedriver|chrome.*chrome_user_data'
```

Nếu có tiến trình lì không chịu chết thì mới dùng bản mạnh tay:

```bash
pkill -9 -f 'python.*zalo|python.*crawler|chromedriver|chrome.*chrome_user_data'
``` 🦋
